# План: кто где заводится — бот и ERP

Решение Шоха (сентябрь 2026), упрощённый вариант. Статус шагов отмечать здесь.

## Правило
- **Плитка бота → «Telegram-сотрудники» — только агенты и водители.** У них нет ERP,
  только бот. Водители заводятся сами из SalesDoctor (`src/driver-sync.js`).
- **Руководители (РОП, логистика, маркетинг, админ) — пользователи ERP**
  (Админ-панель → Пользователи): логин и пароль для веба и «Телефон (Telegram)».
  **Роль в боте берётся из роли ERP**: в Админ-панели → Роли у роли «РОП» выбрано
  «Руководитель продаж», у «Логистика» — «Логистика» (`roles.bot_role`). Отдельного
  поля у пользователя нет — не дублируем. Несколько ролей — берётся старшая.
- Галочки «доступ в веб» нет: логин и пароль — это и есть веб. (Колонка
  `users.web_access` в базе осталась со значением «да» и не показывается.)

      только агента или водителя; роль в боте — у роли ERP (Админ-панель → Роли).

      эскалации претензий, логистика — сводки доставки, подписки на оповещения).
      Старые строки руководителей в плитке бота продолжают работать, дубли
      сообщений исключены (по чату).
- [ ] **3. Перенос двух руководителей** (Абидов — логистика, О'гилой — РОП): в их
